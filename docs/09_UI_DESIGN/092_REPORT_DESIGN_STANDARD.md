## Purpose

This document defines the visual and functional standard for platform reports.

Reports must be suitable for engineering meetings, contractor communication, management review, and audit records.

---

## Report Philosophy

Reports are engineering documents, not raw exports.

Every report must look professionally designed and must clearly communicate conclusions, evidence, and supporting data.

---

## Standard Report Structure

Reports should include:

- ACC branding from platform settings
- Contractor branding where applicable
- Report title
- Report number or reference
- Generation date
- Generated by
- Filter criteria
- Executive / engineering summary
- Data tables
- Charts where useful
- Notes / assumptions
- Footer

---

## Preview Before Export

All interactive reports must support preview before export.

User workflow:

```text
Select report
Apply filters
Preview report
Export PDF / Excel
```

---

## Export Formats

Approved formats:

- PDF for formal reports
- Excel for data analysis

CSV is not required unless separately approved.

---

## PDF Quality Standard

PDF exports must:

- Use professional spacing
- Have clear headings
- Avoid broken page sections
- Keep tables readable
- Include page numbers
- Preserve status colors where required

---

## Excel Quality Standard

Excel exports should be clean and structured.

Excel may be more data-heavy than PDF but still must include readable headers and consistent field names.

---

## Oil Analysis Report Rule

Oil Analysis reports must preserve original lab report status colors where extracted from PDF/OCR.

If a cell is red/yellow/green in the lab report, the app report should preserve that meaning where available.

---

## Contractor Isolation

Reports must respect user scope.

ACC users may see all contractors.

Contractor users may only see their assigned contractor scope.

---

## Scheduled Reports

The design shall support future scheduled email delivery, but scheduling implementation may be deferred.

---

## Engineering Rules

UI-092-001: Raw draft exports are not acceptable as final reports.

UI-092-002: Every report must support preview before export unless technically impossible.

UI-092-003: PDF and Excel are the standard export formats.

UI-092-004: Reports must enforce contractor isolation.

UI-092-005: Report templates should be configurable where practical.
