# ACC Reliability Platform — UI/UX Documentation Package

## Purpose
This package adds the approved UI/UX documentation structure to the ACC Reliability Platform Architecture repository.

## Correct Location
Place these folders inside the Architecture / Documentation repository, not inside the implementation source code.

```text
Architecture/
├── 09_UI_UX_STANDARDS/
└── 10_MODULE_UI_DESIGNS/
```

Implementation projects in Cursor or Claude Code must consume these documents as approved specifications.
